# Pavlok Super Chat Controller for わんコメ

バージョン1.6.0 / わんコメ5.2以降 / Windows

わんコメが取得したYouTubeのSuper Chatを検出し、最大4つの対象金額と完全一致したときにびりびり抽選を行うプラグインです。金額枠ごとに独立した抽選・電撃出力・WordParty演出を設定できます。YouTube APIキーやGoogle OAuth設定は不要で、限定配信の取得可否はわんコメ側のログイン状態に従います。

## 対象と安全上のルール

- YouTubeの`giftType=superchat`だけが対象です。通常コメント、Super Sticker、メンバーシップ、ギフトは対象外です。
- 通貨はJPY固定、対象金額は最大4枠まで設定でき、整数円の完全一致で判定します。有効な金額枠同士で同じ金額は設定できません。
- 金額枠1は常に有効で、追加の金額枠2～4は個別に有効化できます。無効な追加金額枠は設定内容を折りたたみます。
- 各金額枠には名前を設定でき、11個の抽選枠、WordParty演出、待機時間、固定／ランダム電撃出力を別々に持ちます。
- はずれ1は常に抽選対象です。それ以外の10枠はカードごとに使用を選択でき、初期状態ではあたり・確変・はずれ1～4が有効です。
- 使用する各枠には1～10の重みを設定し、重みの比率で抽選します。あたりと追加あたりは電撃1回、確変は電撃2回、はずれ1～8は電撃なしです。
- WordParty連携では、各金額枠で使用する抽選枠に設定した別々の演出を1回実行します。
- 11枠それぞれにWordParty演出時間と名前を設定でき、各カードの「手動実行」でWordParty演出と電撃を含む枠全体の動作を確認できます。
- Pavlok刺激は電撃固定、出力は1～100です。
- 対象イベントは到着順にFIFO予約し、待機中も後続予約を破棄しません。
- WordParty連携ONでは、あたりと追加あたりはWordParty呼び出し後から電撃まで、確変はWordParty呼び出し後から1撃目までの待機秒数を個別に設定できます。確変は1撃目から2撃目までの待機秒数も設定できます。
- 予定した電撃はそれぞれ1回だけ送信し、失敗した電撃を自動再送しません。確変の途中で失敗した場合は残りを送信しません。
- 401/403ではPavlok tokenだけを更新し、失敗した電撃と同じ抽選結果の残りは送信しません。新しいtokenは次の予約から使用します。
- 監視停止時は未処理予約を破棄し、永続化しません。
- WordParty演出の失敗は自動再実行せず、Pavlokの電撃処理は継続します。
- プラグイン起動時は保存設定を読み込み、自動で監視を開始します。Pavlok認証などで開始できない場合は停止状態を保ち、ログへ理由を表示します。
- Pavlok APIキーまたは初期トークンはElectronのOS暗号化機能で暗号化保存します。認証応答にruntime tokenが含まれない環境では、保存したAPIキーをそのままBearerトークンとして使用します。暗号化が使えない環境では保存を拒否します。
- 監視停止中は、1～100の出力値を指定して手動電撃テストを1回実行できます。実機送信OFFではDRY-RUNになります。

## インストール

1. わんコメを終了します。
2. わんコメ右上メニューの「プラグイン」から「プラグインフォルダ」を開きます。
3. 配布ZIPを展開し、`pavlok-onecomme-plugin`フォルダごと配置します。
4. わんコメを起動し、プラグイン画面で「再読み込み」を押します。
5. `Pavlok Super Chat Controller`を有効にします。
6. 一覧に表示されたURLボタンから設定画面を開きます。

フォルダ構造は次の状態にします。

```text
onecomme\plugins\pavlok-onecomme-plugin\plugin.js
onecomme\plugins\pavlok-onecomme-plugin\index.html
onecomme\plugins\pavlok-onecomme-plugin\app.js
onecomme\plugins\pavlok-onecomme-plugin\style.css
```

公式手順: [わんコメ「プラグインの導入」](https://onecomme.com/docs/feature/plugins/)

## 初回設定

1. 設定画面を開きます。プラグイン起動時に監視は自動開始されています。
2. 「監視停止」を押して設定を変更できる状態にします。
3. 最初は「実機へ電撃を送信」をOFFにします。
4. 金額枠名、びりびり対象金額、出力、抽選枠の使用チェックと重み、検出後の待機秒数、各電撃までの待機秒数を設定して保存します。
5. WordPartyも使う場合は、下記の手順で使用する枠の演出IDと演出時間を設定します。
6. 「監視開始」を押します。
7. わんコメのコメントテスターで、サービスをYouTube、ギフト種類をSuper Chat、通貨をJPYにして確認します。
8. ログに`[SUPERCHAT]`、`[MATCH]`、`[LOTTERY]`が順に出ることを確認します。当選時はさらに`[DRY-RUN]`が表示されます。WordParty連携ONでは`[WORDPARTY]`も表示されます。
9. Pavlok APIキーまたは初期トークンを入力し、「実機へ電撃を送信」をONにして保存します。

Super Stickerでは作動しないこと、対象外金額では`[SKIP]`になることも確認してください。
コメントテスターを続けて複数回送信した場合も、各送信を別のSuper Chatとして処理します。同じイベントがわんコメから再配信された場合は重複処理しません。

## 手動電撃テスト

設定画面の「手動電撃テスト」で出力値を1～100から指定し、「手動実行」を押します。未保存の設定は先に保存されます。「実機へ電撃を送信」がOFFならPavlokへは送信せず、ログへDRY-RUN結果だけを表示します。ONならPavlokへ電撃を1回送信します。

この出力値指定の手動電撃は監視中に実行できません。Pavlokが401/403を返した場合はtokenだけを更新し、失敗した手動電撃は再送しません。

## 抽選枠の手動実行

各金額枠の抽選カードにある「手動実行」は、その金額枠の出力設定を使い、選んだ枠のWordParty演出、演出時間、電撃待機、電撃回数を一式で実行します。あたりと追加あたりは電撃1回、確変は電撃2回、はずれ1～8は電撃なしです。チェックOFFの抽選カードも事前確認できます。実機送信OFFでは電撃部分がDRY-RUNになります。

監視中にも使用できます。監視中に押した場合は通常のSuper Chatと同じFIFOの末尾へ予約されるため、進行中の演出を割り込ませません。監視停止中に押した場合は、カードの編集内容を保存してからその場で実行します。

## 開始前のSuper Chat

「開始前のSuper Chatを既読扱いにする」はONを推奨します。ONの場合、監視開始前にわんコメが保持していたSuper Chatは電撃判定せず、既読にしたSuper Chat件数だけをログへ表示します。OFFの場合は、プラグインが保持中の未処理Super Chatを古い順に予約します。

## びりびり抽選

びりびり対象金額は最大4枠まで設定できます。金額枠1は常に有効で、追加の金額枠2～4には使用チェックがあります。有効な金額枠には重複しない整数円を設定し、完全一致した金額枠の抽選設定だけを使います。各金額枠の名前、出力、待機時間、11抽選枠、WordParty演出は独立しています。

- あたり: 初期ON、電撃1回
- 確変: 初期ON、電撃2回
- はずれ1: 常にON、電撃なし
- はずれ2～4: 初期ON、電撃なし
- 追加あたり: 初期OFF、電撃1回
- はずれ5～8: 初期OFF、電撃なし

はずれ1以外の10カードには「この枠を抽選に使用」チェックがあります。使用中の各枠へ1～10の整数で重みを設定し、重み合計に対する比率で1枠を抽選します。各カードの中で枠名、対応するWordParty演出ID、演出時間を設定し、あたり・追加あたり・確変には電撃待機時間も設定します。金額枠名と抽選枠名は1～40文字で変更できます。

電撃出力は固定または指定範囲内のランダムを選べます。電撃のタイミングは次の4項目で設定します。

- あたり: WordParty呼び出し後から電撃まで
- 追加あたり: WordParty呼び出し後から電撃まで
- 確変: WordParty呼び出し後から1撃目まで
- 確変: 1撃目から2撃目まで

最初の3項目はWordParty連携ONの場合だけ適用します。確変の1撃目から2撃目までの待機はWordParty連携のON/OFFにかかわらず適用します。設定範囲はいずれも0～86400秒です。DRY-RUNでも同じ抽選と待機を再現します。

## WordParty連携

1. わんコメのWordPartyで、有効な各金額枠の使用する抽選枠に対応する演出を用意します。
2. 各演出の編集画面上部に表示される8文字のIDをコピーします。同じ金額枠で使用する枠には別々のIDが必要です。
3. プラグイン設定画面で、金額枠ごとの各抽選枠へ演出IDと演出時間を入力します。
4. 「抽選結果に応じてWordParty演出を実行」をONにして保存します。
5. OBSへWordPartyテンプレートを追加し、演出を表示できる状態にします。

プラグインは抽選後にローカルAPIの`POST http://localhost:11180/api/wordparty/{演出ID}`を呼び出します。各使用枠は別々の演出IDに対応し、選ばれた1枠の演出を1回だけ実行します。WordParty連携はPavlokの実機送信設定とは独立しているため、PavlokがDRY-RUNでもWordParty連携がONなら演出は実行されます。WordPartyがHTTPエラーまたは通信エラーになった場合は再実行せず、同じ抽選のPavlok処理は止めません。

各枠の演出時間はWordParty APIの呼び出し開始時点から数えます。FIFOの次予約は、現在の枠の演出時間と電撃処理の両方が終わってから開始します。演出時間を0秒にすると、この待機は行いません。

あたりと確変の最初の電撃までの待機時間は、WordParty APIの応答完了時ではなく、呼び出しを開始した時点から数えます。

API実行ではWordParty側で無効にしている演出も実行されるため、使用しないときはプラグイン側のWordParty連携をOFFにしてください。WordParty API対応版のわんコメ（最新版推奨）を使用してください。

公式資料: [WordParty演出編集](https://onecomme.com/docs/feature/wordparty-editor/) / [WordParty PonKit](https://onecomme.com/docs/feature/wordparty-ponkit/) / [HTTP API](https://onecomme.com/docs/developer/http-api/)

## ログ

設定画面には直近500行を表示します。さらにプラグインフォルダの`logs`へ最大7日・直近10回、1回約1MBまで保存します。トークンやコメント本文は記録しません。

## 配信・利用時の表記

わんコメ公式ドキュメントでは、HTTP APIや連携アプリを無料利用する場合にもクレジット表記が必要と案内されています。配信概要欄などに次の表記を入れてください。

```text
配信コメント取得に「わんコメ」を使用しています。
https://onecomme.com
```

公式資料: [HTTP APIの利用上の注意](https://onecomme.com/docs/developer/http-api/)

## 補足

このプラグインは非公開の旧WebSocket APIへ直接接続しません。わんコメ5.2以降の公開プラグイン機能で`comments`だけを購読します。Pavlokとの通信はプラグインからPavlok公式APIへ、WordParty演出はわんコメのローカルHTTP APIへ送ります。

開発時の回帰試験はNode.js 20以降で`npm test`を実行します。プラグインを利用するだけならNode.jsの別途インストールは不要です。
